# Wedding Invitation - 10 concept intros

Ten standalone online wedding invitations. Each file has its own full-screen, three-second opening ritual rather than a generic floating cover: prism-lit ring alignment, cyanotype contact print, a geometric focus lock, folding origami washi, wax-resist marbling, a tide-pool mirror, Super 8 film transport through a fixed gate, registered giấy dó projection panels, orbital conjunction, and a Seoul metro clearing wet glass. The body keeps the same configurable module schema so copy, assets, music, links, and visibility can be edited without a framework.

Open any file in `templates/` directly. Edit the JSON in `#wedding-config` to change content, show or hide modules, replace photos, choose music, and update links. The opening trigger is a real keyboard/touch button and respects `prefers-reduced-motion`.

The body pass now includes a four-part countdown (days / hours / minutes / seconds), a generated month calendar that marks the configured `dateISO` with a heart, and a matching “Thêm vào lịch” `.ics` action. The Guestbook is a seeded, auto-sliding carousel with previous/next/pause controls; it pauses while hovered or focused, and submitted wishes become new slides without injecting unsanitized HTML. Every module receives an IntersectionObserver reveal with a reduced-motion fallback, and each template now has its own body choreography keyframe: silk wipe, pressed-paper settle, focus lock, washi fold, pigment bloom, tide rise, stepped film advance, projected shadow stage, orbital dial and rain-pane clear. Vietnamese-safe Google font fallbacks (`Noto Serif Display`, `Be Vietnam Pro`, `Noto Sans`) are loaded alongside the concept display fonts.

The responsive hardening pass explicitly protects both layout targets: desktop keeps grid children at `min-width: 0`, while mobile collapses every split layout, reserves safe-area space for the journey bar, moves decorative ornaments away from names/actions, wraps editable names, resets the Washi countdown out of vertical writing mode, and keeps touch controls at least 44px high.

The opening control is a real keyboard/touch button positioned at the centre of the screen in every concept (68px on desktop, 72px on mobile). Its editable label and prompt sit directly below the action, while the art treats the button as the scene's physical trigger. The final names appear only after the action, then the opening fades into the wedding site from 2.64s to 3.0s. While the intro is active, the page behind it is inert for keyboard and assistive-technology focus. Portrait mobile uses a fixed top reading band, a centre action anchor, safe-area-aware navigation, and a short-screen fallback.

Concepts 03 and 09 are intentionally preserved as the approved camera and astrolabe openings. The body now has a final per-template UX/UI polish pass: separate text/surface tokens, audited contrast, visible hover/focus/active states, mobile-safe event cards and forms, and distinct component treatment for each design DNA. See `INTRO_STORYBOARDS_10.md` for the exact mechanism and timing of every opening. `validate-concepts-10.mjs` checks the standalone files, all 17 configurable modules, date/countdown/calendar/guestbook hooks, distinct intro markup, CSS diversity, and the fixed-gate Super 8 transport requirement.
