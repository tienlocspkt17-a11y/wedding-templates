# EverAfter Wedding - Customer Submissions
Thư mục này tự động lưu trữ toàn bộ thiệp cưới mà khách hàng đã chỉnh sửa và chốt đơn từ website.

## Cấu trúc mỗi đơn:
- `submissions/<cardId>/index.html`: File thiệp hoàn chỉnh 100%, standalone.
- `submissions/<cardId>/order.json`: Thông tin khách hàng, số điện thoại, ghi chú.
